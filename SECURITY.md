# Security policy

Please do not disclose API tokens, message bodies, node identities, coordinates,
or vulnerable live MeshMonitor instances in a public issue.

For a security report, use GitHub's private vulnerability reporting feature on
this repository. Include the affected version, impact, and a minimal sanitized
reproduction. Do not test write operations against infrastructure you do not
own or administer.

Only the latest release receives security fixes while the project is pre-1.0.
